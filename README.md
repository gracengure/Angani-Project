# Angani Weather App

#### Date: June 06, 2026
#### By: Grace Wairimu Ngure

## Project Description
Angani is a modern, real-time weather application designed specifically for Kenya. It provides accurate and up-to-date weather information for 14 major cities across the country. The platform features live weather conditions, interactive hourly forecasts, a 7-day outlook, AI-powered summaries, and dynamic backgrounds that change according to current weather conditions.

Users can easily switch between cities, toggle between Celsius and Fahrenheit, and view beautiful, responsive weather visualizations.

## Project Problem Solution
Many Kenyans struggle to access reliable, localized, and easy-to-understand weather information. Angani solves this by delivering real-time weather data from the WeatherAI API in a clean, fast, and visually appealing interface. It helps users plan their day, trips, and activities with accurate hourly and daily forecasts tailored to Kenyan cities.

## Minimum Viable Product (MVP)
The MVP includes:
- Live weather data for multiple Kenyan cities
- Current weather conditions 
- Interactive hourly forecast chart
- 7-day weather forecast
- Temperature unit toggle (°C / °F)
- Responsive and modern user interface

## Installation
You use git clone to download the project from GitHub.

## Installation Requirements
- Node.js (v18 or higher)
- npm or yarn
- Git

### Installation Instructions
git clone https://github.com/yourusername/angani-weather.git
cd angani-weather
npm install

### Environment Setup
Create a .env.local file in the root directory and add your API key:
## envNEXT_PUBLIC_WEATHERAI_API_KEY=your_api_key_here

## Running the Application
- npm run dev
- Open http://localhost:3000 to view the app.
